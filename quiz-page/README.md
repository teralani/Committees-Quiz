# Committee Quiz

A quick and simple way for Model UN delegates to find their ideal committee within a conference. 

Delegates start by selecting how many conferences they've attended to measure their experience level and then answer the following multiple choice questions to gauge their interests in certain topics.

Site administrators can manage their quiz to add, delete, and modify questions.

## Getting Started
To properly be able to use the website, please follow the instructions below, depending on your intended view. The **Delegate View** shows what the main website would look like and the **Admin View** shows the website dashboard.

<details>
<summary><strong>Delegate View</strong></summary>

1.  Navigate to the main [committee quiz website](https://committees-quiz.vercel)
2.  Select your desired quiz.
3.  Answer the questions given on screen.
4.  Explore your tailored committee results!
    - The percentage given for each committee is the compatability score between you and your committee
    - Click the button at the bottom of a committee card to view the official conference page for that committee.
</details>

<details>
<summary><strong>Admin View</strong></summary>

1.  Navigate to the main [committee quiz website](https://committees-quiz.vercel)
2.  Click sign-in on the top right.
3.  Log in using your credentials.
    - If an admin account needs to be created, please contact your conference Board of Directors
4.  Read the documentation tab in your dashboard!
    - To better understand how the quiz works, including the dashboard panels, please read the the documentation fully.
5. Select your conference from the dropdown menu.
6. Create your conference's very own committee quiz!
</details>

## Deployment

### Tech Stack

This project is built using [Next.js](https://nextjs.org), [Supabase](https://supabase.com), and [Vercel](https://vercel.com).

All conference and account data is stored in Supabase, and site analytics and deployment are both handled in Vercel.
